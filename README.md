#### About This Application:

##### **Chensofandog** is a fan-created web application dedicated to the world of ***Chainsaw Man***, designed as an immersive digital space for fans of the anime, manga, characters, artwork, and unique visual style of the series.

##### Rather than functioning as a traditional information or wiki-style website, Chensofandog takes a more **visual, interactive, and atmospheric approach** to presenting its content. The application combines a dark, stylized interface with dynamic layouts, character-focused artwork, interactive navigation, and responsive design elements to create an experience that reflects the chaotic, gritty, and occasionally surreal tone associated with *Chainsaw Man*.

##### The project was built as a hands-on **Node.js and ExpressJS web application**, utilizing server-side rendering through **EJS templates** and a combination of **Bootstrap, CSS, and JavaScript** for the front-end presentation. The application is structured around reusable views and static assets, allowing individual sections of the site to maintain a consistent visual identity while still providing room for unique layouts and interactions.

##### <ins>Project Purpose</ins>:

##### The primary goal of Chensofandog is to explore how a fan-focused website can combine **web development, visual design, and popular culture** into a cohesive interactive experience.

##### The project emphasizes:

* ##### **Immersive visual presentation** rather than purely text-based content
* ##### **Responsive and intuitive navigation** across different screen sizes
* ##### **Character and artwork-driven layouts** inspired by the visual identity of *Chainsaw Man*
* ##### **Interactive content areas** that encourage users to explore the site
* ##### **Reusable server-side templates** for maintaining consistency throughout the application
* ##### **Clean separation between application logic, views, and static assets**
* ##### **Practical deployment experience** using a cloud-hosted Node/Express environment

##### <ins>Design Philosophy</ins>:

##### The visual design of Chensofandog intentionally embraces a **dark and dramatic aesthetic**. High-contrast imagery, bold typography, vibrant artwork, and layered backgrounds are used to create a presentation that feels closer to an interactive fan experience than a conventional informational website.

##### The interface takes inspiration from the visual language of *Chainsaw Man* without attempting to reproduce the original work directly. The goal is to create something that feels familiar to fans while maintaining its own identity as a web development project.

##### The site's design also places an emphasis on **discoverability and exploration**. Content is presented in a way that encourages visitors to move between sections, interact with different elements, and spend time exploring the site's artwork and information.

##### <ins>Technical Implementation</ins>:

##### Chensofandog is built around the following technologies:

* ##### **Node.js** — JavaScript runtime used to run the application server
* ##### **ExpressJS** — Web application framework responsible for routing and server-side application functionality
* ##### **EJS** — Server-side templating engine used to generate dynamic HTML views
* ##### **Bootstrap** — Responsive front-end framework used for layout and UI components
* ##### **CSS** — Custom styling, visual effects, layouts, backgrounds, and responsive presentation
* ##### **JavaScript** — Client-side functionality and interactive behavior
* ##### **Render** — Cloud hosting platform used to deploy and serve the application

##### The application uses Express routing to manage requests and EJS views to render individual pages. Static resources such as stylesheets, JavaScript files, images, and other front-end assets are maintained separately from the server-side application logic.

##### This structure provides a straightforward foundation for expanding the project with additional pages, content sections, interactive components, and future functionality.

##### <ins>User Experience</ins>:

##### Chensofandog is designed with the idea that a fan website should be more than a collection of pages. The presentation of the content is treated as an important part of the experience.

##### Users can expect:

* ##### A **dark, Chainsaw Man-inspired visual theme**
* ##### Responsive page layouts
* ##### Character and artwork-focused content
* ##### Interactive navigation and media sections
* ##### Visually distinct content areas
* ##### A consistent design language throughout the application
* ##### A casual and approachable presentation intended for fans and newcomers alike

##### The project deliberately balances **functionality and visual storytelling**, using web technologies not only to deliver information but also to establish a particular atmosphere.

##### <ins>Development & Learning</ins>:

##### Chensofandog was also developed as a practical exercise in building and deploying a complete web application. The project provides experience with several important areas of modern web development, including:

* ##### ExpressJS application architecture
* ##### Server-side rendering with EJS
* ##### Routing and request handling
* ##### Responsive web design
* ##### Bootstrap-based layouts
* ##### Custom CSS development
* ##### Client-side JavaScript
* ##### Static asset organization
* ##### Git and GitHub-based development workflows
* ##### Cloud deployment with Render

##### As the project evolves, it can serve as a foundation for experimenting with additional functionality, improved accessibility, richer interactions, content management, testing, and other full-stack development concepts.

##### <ins>Project Status</ins>:

##### Chensofandog is an ongoing personal/fan development project. The current implementation focuses primarily on the **visual presentation, structure, and interactive experience** of the website, with opportunities for additional features and refinements as development continues.

##### Future improvements may include additional content, expanded interactive functionality, improved testing coverage, performance optimizations, accessibility improvements, and further refinement of the site's overall user experience.

##### Ultimately, Chensofandog is both a **Chainsaw Man fan experience and a web development project**—bringing together anime/manga fandom, visual design, and practical ExpressJS development into a single application.

#### **Getting Started:** 
##### Before proceeding with the following steps it is assumed that both [Node.js](https://nodejs.org/en/download/) and [Git](https://git-scm.com/downloads) have been downloaded locally on your system. <br> If not, they can be obtained by clicking on the links provided. Further assistance can be found in the documentation if necessary. 
1. ##### Change the current working directory to the location where you want the cloned directory.
2. ##### **Clone** this repository `$ git clone https://github.com/inglorious-ratbastard/chensofandog.git`
3. ##### In the terminal/command prompt run the `npm install` or `yarn install` command to install the projects dependencies
4. ##### Run the `node index.js` command in the terminal to start the server and run the application

#### Deployment to Render:
##### About: The following explains how this app was deployed to [Render](https://render.com/) Cloud Hosting, assuming that you have already set up an account. Another preferred option for hosting services would be [Railway](https://railway.app/) More information about Render Cloud Services can be found in the [Docs](https://docs.render.com/) section. A brief explanation of how to deploy your project to Render is provided below. 

* ##### Assure that your project has successfully been committed to Github. Any future changes made and pushed up will be directly reflected on [Render](https://render.com/). 
* ##### From the Dashboard click on **New** to connect your Github repo and create your hosted application from the given options (either Static Site or Web Service). 
* ##### Name your projet then scroll down and make sure that the `yarn build` and `yarn start` point to the correct files. *See the Scripts section of `package.json` file for clarification.*
* ##### If you have any global or secret keys you can create them by expanding the **Advanced** tab and manually entering the proper values in the form boxes provided.
* ##### Once all of the above steps have been completed, you can now **Deploy** your project to the Cloud.
